ShopNow – Online Shopping Platform

Full-Stack Project using Spring MVC, HTML, CSS, JavaScript & Bootstrap

Project Overview

ShopNow is an online shopping platform that provides a seamless shopping experience. Users can browse products, search and filter items, add products to their cart, and complete orders. Admins can manage the product catalog efficiently by adding, editing, or deleting products.

Features

For Users:

Browse products with a clean and responsive UI

Search and filter products by name or category

Add/remove products to/from shopping cart

View order confirmation after successful checkout

For Admins:

Add, edit, and delete products

Manage product catalog efficiently

Technologies Used

Backend: Spring MVC (Java)

Frontend: HTML, CSS, JavaScript, Bootstrap

Database: MySQL
